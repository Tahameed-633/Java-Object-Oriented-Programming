# Java OOP

This repository contains my Java Object-Oriented Programming (OOP) practice, examples, and exercises.

## 📚 Topics Covered

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Method Overloading
- Method Overriding
- Abstract Classes
- Interfaces
- Association
- Aggregation
- Composition
- ArrayList
- Exception Handling
- Custom Exception Handling

## 🧩 OOP Concepts

### 1. Classes and Objects
Practice programs demonstrating how classes and objects are created and used in Java.

### 2. Encapsulation
Using access modifiers, constructors, getters, and setters to protect and manage data.

### 3. Inheritance
Practice with parent-child class relationships using `extends`.

### 4. Polymorphism
Examples of method overloading and method overriding.

### 5. Abstraction
Practice with abstract classes and abstract methods.

### 6. Interfaces
Examples of creating and implementing interfaces using `implements`.

### 7. Exception Handling
Practice programs covering:

- `try`
- `catch`
- `finally`
- Multiple `catch` blocks
- Nested `try-catch`
- `throw`
- `throws`
- Common Java exceptions
- Custom exceptions
